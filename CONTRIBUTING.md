# Contributing and bug reports

Please test on actual FM-1 hardware when reporting MIDI/transport issues. State:

1. Firmware identity (for this beta `FM-1_731000535`).
2. Mode (PLAYER / PATTERN / SONG / ALBUM / LIVE PLAY / EDITOR) and active USB/BLE/TRS connections.
3. Steps to reproduce and expected vs actual behavior.
4. Which track(s), pattern IDs, S/M song IDs and ONCE/LOOP mode were used.
5. Relevant build output, without personal paths, account tokens or confidential data.

For the known **ALBUM ONCE** bug see [docs/KNOWN_ISSUES.md](docs/KNOWN_ISSUES.md). Keep original license headers when modifying files.
